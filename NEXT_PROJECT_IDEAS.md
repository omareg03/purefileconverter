## Rules Learned (apply to every future site)

- Amazon affiliate links: use search-URL format `https://www.amazon.com/s?k=<keywords>&tag=purefileconve-20` — NEVER guess ASINs.
- Every blog image: descriptive filename + matching alt text + caption + width/height (no CLS) + lazy loading.
- Every page: unique title, meta description, canonical, JSON-LD schema (Article + WebApplication + FAQ + Breadcrumb).
- robots.txt welcomes AI bots (GPTBot, OAI-SearchBot, PerplexityBot, ClaudeBot, Google-Extended); llms.txt lists all content.
- GZip + Cache-Control: immutable + tiny SVG images = speed is never the bottleneck.
- Render free tier: 5 GB/mo bandwidth handles hundreds of thousands of views.
- AdSense: $100 threshold, paid 21st-26th monthly. Amazon: $10 threshold, ~60-day delay.
