Reporting a problem with a conversion

If a tool shows an error or the result looks wrong, these details help me find the cause quickly:

  • The tool you used, for example "PDF to Word" or "Compress PDF".
  • The type and approximate size of the file (for example "a 4 MB scanned PDF with 12 pages").
  • The exact error message, if one appeared.
  • Your device and browser, for example "iPhone, Safari" or "Windows 11, Chrome".

Please don't email documents that contain personal, financial or medical information. If a sample file is needed, I'll ask for one, and you can send a copy with the private parts removed.

Other reasons to get in touch

  • Tool requests: tell me which conversion you need. Popular requests get built first.
  • Privacy requests: questions about your data or the rights described in the Privacy Policy.
  • Copyright or abuse reports: include the page address and a short explanation.
  • Corrections: if a guide on the blog is wrong or out of date, I'll fix it.

PureFileConverter will never ask you for a password, a payment or remote access to your computer. If someone contacts you claiming to be from this site and asks for any of those, it isn't me.
