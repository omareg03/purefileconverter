# Rule: Micro-SaaS Utility Site Architecture
When requested to build a utility or converter website (Micro-SaaS), you MUST adhere to the following layout and SEO strategies:
1. **The Mega-Grid layout**: The homepage must not be a single tool. It must act as a directory divided into clear categories (e.g., "Document Tools", "Image Tools", "Media Tools").
2. **The 3x4 Rule**: Aim for at least 3 categories with 4 tools each (12 distinct tools total) to maximize SEO keyword coverage.
3. **Dedicated Pages**: Every tool in the grid must link to its own dedicated SEO-optimized route (e.g., `/pdf-to-word`), rather than opening a modal or unified state.
4. **Color Psychology**: Use premium, trustworthy color palettes. Use Blues (#2563EB) for structural elements/trust, and Greens (#16A34A) for primary action/conversion buttons.
